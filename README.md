# 引力跳板 · 星际弹弓轨道规划游戏

一款以**引力弹弓（重力助推）**为核心机制的原创轨道规划游戏。玩家为深空探测器编排动作序列——点火变轨、耐心等待、在木星/土星等行星影响球内完成收紧的双曲飞掠——用最省的燃料把探测器送到火星、外太阳系，最终挣脱太阳引力飞出太阳系。

## 玩法

- **5 个关卡**由易到难：火星飞掠 → 小行星带穿越 → 木星引力捕获 → 土星远航（双弹弓接力）→ 星际逃逸
- 三种动作按顺序编排：
  - **等待**：让后续动作推迟 N 天执行
  - **点火**：指定方向（角度）与 ΔV 消耗燃料
  - **弹弓**：选择目标行星与近心点 b（正负决定绕行方向），探测器进入行星影响球时自动结算
- **物理引擎**：简化 N 体模型（太阳引力 RK4 积分 + 双曲飞掠公式），行星沿真实太阳系轨道参数做圆轨道运动
- **评分**：三星 ≤ 55% 燃料预算、二星 ≤ 80%、通关得星；最佳成绩存档（SQLite）
- **成绩记录**：每次发射落库为可追溯的执行档案（动作方案 + 轨迹 + 结算），成绩关联档案可回放、可载入方案继续调优；提交带幂等键，双击/重试/多标签页不会重复记分；兼容旧版存档
- **社区航线挑战**：设计者发布带燃料/时间预算与里程碑的**版本化关卡**（每次发布生成不可变快照，旧版成绩口径可复现）；玩家提交**幂等结算**的飞行记录（分数以服务端执行档案为准，客户端无法伪造）；记录经**审核**后联动排行榜（按版本隔离）、轨迹回放与挑战解锁（主线每通关一关多开放一组挑战）
- **交互**：实时轨迹预览、滚轮缩放/拖动平移、回放动画、策略提示

## 快速开始

```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. 一键启动（自动挑选空闲端口并打开浏览器）
npm run dev
```

启动后访问控制台输出的地址（如 `http://127.0.0.1:8072`），或直接按 `npm run dev` 自动打开的页面。

## 操作说明

| 操作 | 方式 |
| --- | --- |
| 添加动作 | 右侧面板「+ 等待 / + 点火 / + 弹弓」 |
| 调整参数 | 点击动作展开滑杆（角度/ΔV/天数/近心点） |
| 调整顺序 | 动作行 ↑ / ↓ |
| 查看预测轨迹 | 改动自动触发，画布实时显示 |
| 执行任务 | 右上角「🚀 发射」 |
| 轨迹回放 | 画布左上角 ▶ / ⏸，滚轮缩放、拖动平移 |
| 最佳回放 | 顶部「🏆 最佳回放」（已有关卡成绩时出现），可「载入方案」还原动作序列 |

## 关卡目标

| 关 | 名称 | 目标 | 燃料预算(km/s) |
| --- | --- | --- | --- |
| 1 | 火星飞掠 | 近距离飞掠火星 (< 0.18 AU) | 6.9 |
| 2 | 小行星带穿越 | 越过 4.2 AU | 15.6 |
| 3 | 木星引力捕获 | 木星弹弓后被捕获 | 17.3 |
| 4 | 土星远航 | 土星弹弓后远日点 ≥ 15 AU | 16.4 |
| 5 | 星际逃逸 | 挣脱太阳引力（飞出 40 AU 边界） | 19.9 |

## API

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/system` | 天体参数、关卡信息、最佳成绩（含可回放记录 id） |
| POST | `/api/preview` | 实时预览轨迹（不评分）；带 `challenge_id` 时按挑战当前版本预览 |
| POST | `/api/run` | 执行任务并评分（星级），执行档案落库并返回 `run_id`；带 `challenge_id` 时按挑战当前版本结算 |
| POST | `/api/score` | 提交成绩：`run_id` 关联执行档案 + `submission_id` 幂等键；兼容旧版仅带 `stars` 的提交 |
| GET | `/api/scores/{level_id}/records` | 某关成绩提交记录（追溯列表） |
| GET | `/api/records/{record_id}` | 成绩记录详情：动作方案 + 轨迹（供回放） |
| GET | `/api/challenges` | 挑战列表（含解锁状态）+ 已解锁组数 |
| POST | `/api/challenges` | 发布挑战（含首个版本 v1）：里程碑 + 预算 + 提示 |
| GET | `/api/challenges/{id}` | 挑战详情：当前版本关卡定义 + 历史版本列表 |
| POST | `/api/challenges/{id}/versions` | 发布新版本（旧版本快照保留，排行榜按版本隔离） |
| POST | `/api/challenges/{id}/entries` | 提交飞行记录：`run_id` + `submission_id` 幂等键，默认待审核 |
| GET | `/api/challenges/{id}/entries` | 飞行记录列表（可按 `status`/`version` 过滤，审核队列用 `status=pending`） |
| GET | `/api/challenges/{id}/entries/{entry_id}` | 飞行记录详情：动作方案 + 轨迹（供回放） |
| POST | `/api/challenges/{id}/entries/{entry_id}/review` | 审核：`approve` 进排行榜 / `reject` 留痕不计成绩 |
| GET | `/api/challenges/{id}/leaderboard` | 排行榜（仅已审核通过且任务达成，可按 `version` 查询） |

## 社区航线挑战

主线之外的玩家共创模式（主页「🌐 社区航线挑战」进入）：

- **设计者**：「＋ 发布挑战」定义关卡——里程碑（飞掠/抵达半径/弹弓捕获/逃逸）、燃料预算（km/s）、时间预算（天）与策略提示；发布后生成不可变的 **v1 快照**。后续修改走「发布新版本」：旧版本的关卡定义、成绩与排行榜全部保留，结算口径可复现。
- **玩家**：进入挑战后与主线同一套编排/物理玩法；「🚀 发射」由服务端按挑战当前版本结算，飞行记录带幂等键提交（双击/重试/多标签页不会重复入库），默认**待审核**。
- **审核联动**：审核通过的记录进入排行榜（星数 → 燃料 → 耗时排序，按版本隔离）并计入挑战进度；驳回留痕可回放但不计成绩。排行榜与提交记录中的每条记录都可**回放轨迹**。
- **解锁**：第 1 组挑战默认开放；主线每通关一关（≥1 星）多开放一组（每组 3 个槽位，先发布先得）。

## 物理模型说明

- 距离 AU、时间 天、速度 AU/天（1 AU/天 ≈ 1731.5 km/s）
- 弹弓结算：入轨相对速度 v_inf、近心点 r_p 下，偏转角 δ = 2·asin(1/(1 + r_p·v_inf²/μ))，相对速度大小守恒（能量守恒）
- 行星间互不摄动；探测器在弹弓事件之间只受太阳引力（RK4）
- 近心点小于行星半径会解体；燃料耗尽或超时判负
